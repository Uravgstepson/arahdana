# ArahDana v1.0.0 RC1 Release Notes

Status: release candidate
Tag: `v1.0.0-rc1`
Package version: `1.0.0-rc1`
Release date: 2026-05-27

## Release Scope

ArahDana v1.0 RC is the first official usable release candidate for private beta. It is a portfolio tracking and decision-support app, not a financial advisor.

Included in this release:

- Google login and email/password auth through Supabase.
- Secure user-owned data storage with Row Level Security.
- Portfolio tracking with add, edit, delete, CSV import, and reset flows.
- Home and Porto portfolio views backed by the same authenticated data source.
- Privacy mode for hiding sensitive values on screen.
- App lock and safer local session behavior.
- Market page, market search, watchlist, and public market data helpers.
- Goals for DCA planning and personal financial targets.
- Analysis flow for structured, deterministic investment review.
- CSV import for local portfolio onboarding.
- Feedback system stored in Supabase without sensitive financial values.
- Error monitoring, Vercel Analytics, and Speed Insights.
- PWA readiness with manifest, service worker registration, and installable app shell.
- Legal/trust pages: disclaimer, privacy, terms, and account/data deletion.

## Known Limitations

- ArahDana does not provide financial advice or guaranteed investment outcomes.
- Market data can be delayed, unavailable, or provider-limited.
- CSV import still depends on supported formats and clean exported data.
- No direct bank, broker, e-wallet, OTP, or credential-based integrations.
- Supabase schema migrations must be applied before account deletion and feedback storage are production-ready.
- Live regression for login, deletion, PWA install, and cross-user isolation must be run against the production Supabase/Vercel environment before broad release.
- Beta feedback content in this repo is a product summary, not a complete export of private user messages.

## Feature Freeze

Until v1.0 final, only these changes should be accepted:

- P0/P1 bug fixes.
- Security, privacy, RLS, or data-loss fixes.
- Release copy, legal copy, and documentation corrections.
- Monitoring or deployment configuration fixes.
- Small accessibility or loading-state fixes that do not change product scope.

Defer to v1.1:

- New asset classes or advanced portfolio models.
- Broker/bank integrations.
- Automated recommendations.
- Social/sharing workflows.
- Large visual redesigns.
- New dashboards that duplicate existing Home, Porto, Market, Goals, or Analysis surfaces.

## Database And Security Check

Schema file: `supabase/arahdana-schema.sql`

Verified from the schema file:

- User-owned tables exist for profiles, portfolios, holdings, watchlist, settings, analysis, feedback, goals, goal contributions, alerts, reports, and beta feedback.
- Row Level Security is enabled for all app data tables.
- User-owned policies scope data with `auth.uid() = user_id` or profile `id`.
- Delete policies exist for user-owned portfolio, holdings, watchlist, settings, goals, alerts, reports, feedback, and beta feedback data.
- `delete_current_user_account()` removes user-owned app data and the auth user.
- Public beta signup is limited to insert-only public access.

No demo portfolio data should render inside authenticated Home, Porto, Analysis, Market, Goals, or Settings routes.
